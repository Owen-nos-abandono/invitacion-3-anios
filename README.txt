# Invitación Frozen — Cumpleaños de 3 años

## Archivos
- `index.html` — estructura de la invitación.
- `styles.css` — diseño, colores, tarjetas y animaciones.
- `script.js` — botón de confirmación por WhatsApp.

## Cómo abrirla
1. Mantén los tres archivos en la misma carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Para probar WhatsApp, presiona "Confirmar asistencia".

## Número de prueba
4423296104

En `script.js` se utiliza el formato internacional de WhatsApp para México:
`524423296104`

## Para cambiar el número después
En `script.js`, modifica:
`const whatsappNumber = "524423296104";`

No agregues el signo `+`, espacios ni guiones.

## Ubicaciones
Los botones de ubicación abren búsquedas de Google Maps con las direcciones proporcionadas.
